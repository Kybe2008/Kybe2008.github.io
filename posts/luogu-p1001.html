洛谷算法打卡初体验：P1001 A+B Problem 解题与判题机制揭秘

作者：林国 (Kybe) · 发布时间：2026-09-09 · 标签：算法竞赛, 洛谷

今天在洛谷 Online Judge 平台上顺利拿下了人生中第一个全绿 AC。看似简单的加法题，背后蕴含了计算机输入输出的深层机理。

一、 核心源码实现

#include <iostream>

int main() {
    int a, b;
    std::cin >> a >> b;
    std::cout << a + b << std::endl;
    return 0;
}

二、 判题机原则

OJ 评测机采用严格的标准输出字符比对，任何多余的提示符（如“请输入数字”）都会导致判题失败。坚持规范代码习惯至关重要！
