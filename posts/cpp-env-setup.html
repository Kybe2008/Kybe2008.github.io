从零搭建 VS Code + C++ (MinGW-w64) 与 Git 编译环境实战复盘

作者：林国 (Kybe) · 发布时间：2026-09-08 · 标签：开发环境, C++

在进行计算机科学学习的第一天，搭建一个属于自己、干净规范的本地开发环境是最重要的基石。本文复盘全套工具链在 D 盘部署的全过程。

一、 统一文件架构 (D 盘规范分类)

为了避免占用系统 C 盘空间并规避空格路径问题，所有开发工具统一归类部署于 D:\DevTools，工程项目位于 D:\Workspace。

二、 核心编译命令

# 使用 g++ 现代 C++20 静态编译
g++ -std=c++20 -static hello.cpp -o hello.exe
# 运行程序
.\hello.exe

通过本次搭建，深刻理解了 PATH 环境变量的本质，迈出了程序员独立开发的第一步！
