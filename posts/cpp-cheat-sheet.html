📘 C++ 小白做题速查宝典

整理：林国 (Kybe) · 适用：洛谷新手入门 · 随时开卷查阅
🌟 手机随身口诀：
刚学编程记不住模板完全正常！做题时手机横屏或竖屏放在桌边，当字典随时看。照着写上 10 道题，手指自然形成肌肉记忆！

模块一：万能起手式（任何题目的固定骨架）

新建 .cpp 文件后，二话不说先把这个骨架抄上去，所有解题逻辑全写在大括号里：

#include <iostream>
using namespace std;   // 加上这句，省去每次写 std::

int main() {
    // 👉 你的所有解题代码全写在这里！
    
    return 0;
}

逐行原理大白话：

  • #include <iostream>：向系统借调专门管屏幕打印和键盘输入的工具箱。
  • using namespace std;：默认在官方标准库里找东西，允许直接写 cin 和 cout。
  • int main() { ... }：程序的唯一大门，电脑从这里作为第一行起跑。
  • return 0;：程序执行完毕，向系统交卷汇报：“状态码 0，一切正常无报错！”

模块二：数据抽屉（变量类型）

根据题目要装什么数据，挑对应的单词建抽屉：

类型关键字装什么？范围与特点例子
整数int正数、负数、0约正负 21 亿，最常用int a = 10;
超大整数long long超 20 亿大数高达 ±9×1018，大数相乘必备long long n;
小数double带小数点的数精度高，算平均数必备double pi = 3.14;
字符char单个字母符号必须用单引号包裹char c = 'A';
字符串string一串文字名字必须用双引号包裹string s = "Kybe";
布尔bool对与错true (1) 或 false (0)bool ok = true;

模块三：耳朵与嘴巴（输入输出）

1. 读入数据（从键盘灌进抽屉）

int a, b;
cin >> a;          // 读一个数放进 a
cin >> a >> b;     // 连续读入两个数（空格或回车隔开都行）

箭头记法：>> 漏斗朝右，数据从左边键盘流进右边抽屉。

2. 屏幕输出（把结果吐到屏幕）

cout << a;                     // 打印变量 a 的值
cout << a + b;                 // 算完后直接把和打印出来
cout << a << endl;             // 打印并换行（endl = end line）
cout << a << " " << b << endl; // 两个数字中间空一格输出

箭头记法：<< 传送带朝左，把右边内容推送到左边屏幕。

3. 保留两位小数标准模板：

#include <iostream>
#include <iomanip> // 👉 必须包含格式控制工具箱
using namespace std;

int main() {
    double x = 3.1415926;
    cout << fixed << setprecision(2) << x << endl; // 输出：3.14
    return 0;
}

模块四：符号字典（运算与判断）

1. 四则运算

  • 加减乘：+、-、*
  • 除法 /（新手最大天坑）：两个整数相除 5 / 2 结果是 2（小数会被切掉！）；必须写成 5.0 / 2 结果才是 2.5。
  • 求余数 %：7 % 3 结果是 1。常用于判断偶数：if (x % 2 == 0)。

2. 比较符号

  • >、<、>=、<=、!=（不等于）
  • ==（新手最容易错！）：一个等号 = 是赋值（塞入东西）；两个等号 == 才是判断相等！

3. 逻辑连接符

  • 并且 &&：两边都必须满足（如 score >= 60 && score < 90）。
  • 或者 ||：只要一个满足就行（如 year % 400 == 0 || year % 4 == 0）。

模块五：做选择（分支结构 if - else）

if (score >= 90) {
    cout << "优秀" << endl;
} else if (score >= 60) {
    cout << "及格" << endl;
} else {
    cout << "不及格" << endl;
}

模块六：重复劳动（循环结构 for 与 while）

1. for 循环（明确知道跑几圈，做 N 次）

// 结构：for (起跑点; 终点线; 计数器自增)
int n;
cin >> n;
int sum = 0; // 重点：求和变量必须先清零！
for (int i = 1; i <= n; i++) {
    sum = sum + i;
}
cout << sum << endl;

2. while 循环（条件满足就一直跑）

int n = 12345;
int count = 0;
while (n > 0) {
    n = n / 10; // 砍掉末尾数字
    count++;    // 位数加 1
}
cout << count << endl;

模块七：洛谷 OJ 判题机制与避坑保命指南

  • 🟢 AC (Accepted - 绿色)：满分通过！
  • 🔴 WA (Wrong Answer - 红色)：答案错误。检查算出的数字是否跟样例一致。
  • 🟡 CE (Compile Error - 黄色)：编译错误。漏了分号、拼错单词，看具体报错行。
  • 🟣 TLE (Time Limit Exceeded - 紫色)：超时。死循环了。
三大保命铁律：
  1. 绝对不要写多余人机提示：绝不能写 cout << "请输入数字:";，判题机会直接判 WA！
  2. 每行语句末尾必须带英文分号 ;。
  3. 累加求和变量必须初始赋 0：int sum = 0;，否则里面装的是电脑内存垃圾值！
